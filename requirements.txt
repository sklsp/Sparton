# SPARTON -- the product.
#
# This file installs what the SHIPPED product needs, and nothing else. The image
# is built from it, so every line here is a few hundred megabytes of a deploy,
# and anything here that the product does not import is a mistake.
#
# The feature-flagged experimental domains (documents/RAG, generation, datasets,
# training) have their own file: requirements-experimental.txt. They are off by
# default (ENABLED_DOMAINS=intelligence,commerce,agent) and are not installed in
# the image. Their heavy dependencies -- sentence-transformers and faiss-cpu,
# which pull in the whole PyTorch stack -- were what made the image 9.8 GB.
#
# That was possible because app/main.py imported the experimental routers
# unconditionally, so `import app.main` reached sentence_transformers and faiss
# whether or not a single document route was mounted. Those imports are now
# inside the feature-flag branches: a disabled domain has no routes and is not
# even imported.
#
# To run the experimental domains locally:
#     pip install -r requirements-experimental.txt
#     ENABLED_DOMAINS=intelligence,commerce,agent,documents,generation,datasets,training
